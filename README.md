# Music AI Kit Website

音楽アーティスト制作キッド「AIチーム(GPTs版) & AI搭載アプリ」の公式ウェブサイトです。

## 機能

- レスポンシブデザイン
- セキュアなログイン認証システム
- AIチーム（GPTs）紹介セクション
- AI搭載アプリ（Nano Banana）セクション（タブ機能付き）
- アニメーション波形ビジュアル

## ログイン情報

**パスワード:** `ai-teme-music26`

## セキュリティ機能

- SHA-256によるパスワードハッシュ化
- セッション管理（1時間の自動タイムアウト）
- ブルートフォース攻撃対策（5回の試行失敗で5分間ロックアウト）
- sessionStorageによる安全なセッション保持

## ファイル構成

```
├── index.html          # メインページ
├── login.html          # ログインページ
├── style.css           # メインスタイルシート
├── login-style.css     # ログインページスタイルシート
├── script.js           # メインJavaScript（タブ機能など）
├── auth.js             # 認証システム
└── README.md           # このファイル
```

## 使用方法

1. `login.html`をブラウザで開く
2. パスワード `ai-teme-music26` を入力してログイン
3. メインページ（index.html）にアクセス
4. ログアウトする場合は、ヘッダーの「ログアウト」ボタンをクリック

## セキュリティに関する注意

このシステムはフロントエンドのみの実装です。本番環境での使用には、以下を推奨します：

- バックエンドサーバーでの認証処理
- HTTPSによる暗号化通信
- データベースでのユーザー管理
- JWT（JSON Web Token）などのトークンベース認証
